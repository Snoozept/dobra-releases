# Dobra — test APK releases

Offline Android paper-folding puzzle by IDtech. Test build; translations not native-reviewed.

[Download Dobra 0.4.0-test](https://github.com/Snoozept/dobra-releases/releases/download/v0.4.0-test/dobra-amostra.apk)

200 story levels; hard challenges every 5 levels and extra-hard every 10. Fold the paper, then drag Pip along the road to collect the key and reach the door. Optional automatic route in Settings. Lands change at levels 50 and 100. English on each launch; ten session languages. Progress is preserved from earlier builds.

Enable installation from this source only if you trust this test APK. Debug-signed; same Dobra signing identity as previous tests. The app checks the public [latest.json](latest.json) and opens Android’s installer only after you tap Update.

This repository contains distribution metadata and APK release assets only. No game source or signing keys.
